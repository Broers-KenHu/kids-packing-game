# 小小打包台

给小朋友在平板上玩的小游戏：拖箱子、扔箱子、叠箱子；点箱子包上泡泡纸，一个个戳破泡泡（啪、啵、噗），全部戳破就打包好了。
打包好的箱子飞进小货车，装满 5 个货车就开走；箱子上的贴纸收进贴纸本，一共 16 张。
有一首轻快的背景小曲（🎵 开关），全部由浏览器现场合成，不加载音频文件。
每送走 5 辆货车进一次大关卡（大卡车要开啦、巨无霸箱子、暴风雨来啦、捣蛋小狗、传送带快跑），不会输，按表现给星星和奖章。
家长想直接试某一关：网址后面加 `?level=1` 到 `?level=5`。

- 打开：https://broers-kenhu.github.io/kids-packing-game/
- 用 iPad 的 Safari 或安卓的 Chrome 打开，「添加到主屏幕」以后就像一个应用，全屏，断网也能玩。
- 整个游戏是一个网页文件，不联网、不用登录、没有广告和外部链接、不收集任何数据；只在平板本机记住「最多打包几个」、收集到的贴纸和声音开关。
